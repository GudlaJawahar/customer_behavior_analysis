
# 📊 Customer Behavior Analysis – End-to-End Data Analytics Project

## 📌 Overview

This project demonstrates a complete end-to-end data analytics workflow using Python, SQL Server, Power BI, and Gamma. The objective was to analyze customer behavior, clean and transform the data, generate business insights, and present the findings through an interactive dashboard and a professional presentation.

---

## 📂 Dataset

The project uses a Customer Behavior Analysis dataset containing customer demographics, purchase information, ratings, subscription status, shipping details, and product categories.

The dataset was used to identify customer trends, purchasing patterns, and business insights.

## 🚀 Project Workflow

### 1. Data Loading
- Imported the dataset into Python using Pandas.
- Examined the dataset structure and data types.

### 2. Exploratory Data Analysis (EDA)
- Explored customer demographics and purchasing behavior.
- Analyzed distributions, trends, and relationships.
- Identified missing values and duplicate records.

### 3. Data Cleaning
- Removed duplicate records.
- Handled missing values.
- Corrected inconsistent data.
- Converted columns to appropriate data types.

### 4. SQL Server
- Connected Python to Microsoft SQL Server.
- Loaded the cleaned dataset into SQL Server.
- Performed SQL queries to extract business insights.

### 5. Power BI Dashboard
Created an interactive dashboard featuring:
- 👥 Active Customers
- ⭐ Average Review Rating
- 💰 Average Purchase Amount
- 🛒 Total Orders
- Revenue by Category
- Sales by Category
- Revenue by Age Group
- Sales by Age Group
- Interactive Filters

### 6. Report & Presentation
- Summarized key findings in a report.
- Created a professional presentation using Gamma.

## ▶️ How to Run

1. Clone this repository.
2. Install the required Python libraries.
3. Open the Jupyter Notebook and run all cells.
4. Connect to Microsoft SQL Server.
5. Execute the SQL scripts.
6. Open the Power BI (.pbix) file.
7. Refresh the data connection.
8. Explore the interactive dashboard.
9. View the Gamma presentation for the project summary.
